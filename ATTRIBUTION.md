# Attribution

This project is adapted from the original repository:

- Original project: [yangkghjh/shimo](https://github.com/yangkghjh/shimo)

This repository is not a verbatim mirror. It keeps the original idea of exporting Shimo documents, and adds practical improvements for a local Windows + Obsidian workflow, including:

- configurable export behavior
- safer local credential handling through environment variables
- more robust file comparison and retry handling
- Obsidian import with deduplication
- Obsidian navigation page generation
- documentation and release packaging for repeated personal use

The current repository is maintained as an adapted and optimized derivative for personal and future workflow use.
